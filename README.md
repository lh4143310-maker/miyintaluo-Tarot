## 项目简介

秘引塔罗是一款微信小程序形态的**专业塔罗测算工具**，全功能免费开放。产品聚焦 "专业解读 + 便捷操作"，通过 5×5 网格翻牌、手动洗牌切牌还原真实占卜流程，并接入 DeepSeek 大模型提供专业级 AI 深度解读。

### 核心特色

- **AI 深度解读** - 接入 DeepSeek Chat API，400-800 字专业解读报告
- **沉浸式体验** - 5×5 网格翻牌、手动洗牌切牌，还原真实占卜
- **动态视觉** - 漂浮粒子、流星、旋转塔罗符号，营造神秘氛围
- **数据固化** - 历史记录保存原始 AI 解读，确保结果一致性

## 核心流程

### 塔罗占卜流程

```
输入问题 → 选择牌阵 → 洗牌 → 切牌 → 5×5抽牌 → AI解读 → 进一步咨询
```

**5×5 网格抽牌**：25 张牌背网格排列，用户点击选择，显示选择顺序，选够后自动跳转结果页。

### AI 深度解读

**技术方案**：
- 模型：DeepSeek Chat (deepseek-chat)
- 知识库：大阿卡纳 22 张 + 小阿卡纳 56 张 + 元素互动 + 数字学 + 占星对应
- 输出：400-800 字专业解读
- 特色：过滤 markdown 符号，保留温馨图案（✦ ☽ ☉）

**进一步咨询**：
- 基于原占卜结果回答追问
- 支持多轮对话
- 咨询历史当前页面保留

## 快速开始

### 开发环境
- 微信开发者工具
- Node.js (可选，用于代码检查)

### 安装运行
1. 克隆项目到本地
2. 使用微信开发者工具打开项目目录
3. 修改 `app.json` 中的 `appid` 为你自己的小程序 ID
4. 编译运行

### 配置说明
- `data/tarotKnowledge.js` - AI 知识库，可扩展塔罗知识
- `pages/reading/result.js` - DeepSeek API Key 配置（生产环境建议改用云函数）

## 注意事项

1. **合规要求**：底部固定合规提示，测算结果仅供娱乐参考
2. **API Key**：DeepSeek API Key 当前硬编码在代码中，生产环境建议改用云函数调用
3. **数据安全**：敏感数据本地存储，符合微信小程序规范
